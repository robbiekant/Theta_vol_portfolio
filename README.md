# Theta_vol_portfolio

A regime-driven **theta / volatility-surface** engine for a $300,000 ETF options
book, built to Ravi's standing rules.

The thesis it tests, in order:

1. **Theta differential.** Front-dated options decay faster than back-dated ones.
   Selling the front and owning the back (a calendar) monetises that difference —
   but only if you are not paying for the privilege in the term structure.
2. **Volatility surface / smile.** Both the *level* (implied vs forecast realised)
   and the *shape* (25-delta risk reversal and butterfly) are separate, tradeable
   inputs. Metals currently carry a rich **call** wing; equity ETFs a rich **put** wing.
3. **Double calendars in low volatility.** The rulebook's own structure map puts
   calendars in the IVR-under-25 cell — vol is cheap, owning it beats selling it.

## Universe

SPY, QQQ, IWM, GLD, SLV, ARKK, SMH, KWEB, FXI, EWZ — ETFs only, no single-name risk.

## What the engine does

| module | job |
|---|---|
| `config.py` | every tunable rule: gates, sizing, deployment, vol-shock model |
| `bs.py` | Black-76 off the **implied forward**, not the cash spot |
| `surface.py` | per-expiry forward from put-call parity, quadratic smile in log-moneyness, term structure interpolated in **total variance**, forward factor |
| `forecast.py` | HAR / 50-50 / 1-year realised-vol forecasts × mid / execution-adjusted IV — the sleeve grid |
| `structures.py` | structure construction, Greeks, expectancy against **real** historical return distributions re-centred to the forward, managed-exit block bootstrap |
| `engine.py` | candidate generation + the gate scorecard, plus the VRP regime sweep |
| `portfolio.py` | beta-weighted delta, correlation, historical-simulation 99% 1-day VaR/CVaR, integer sizing optimiser, income frontier |
| `report.py` | assembles everything and writes `out/*.csv` |
| `dashboard.py` | the HTML task board |

## Run it

```bash
python -m thetavol.cli run          # everything
python -m thetavol.cli screen       # surface screen only
python -m thetavol.cli sweep        # what IV level the 2%/month target needs
```

Every build runs **offline** from the committed snapshot in
`data/snapshots/<date>/`, so any past build is reproducible with no broker
connection. `out/*.csv` is committed; the HTML task board is regenerated by
`python -m thetavol.cli dashboard` into `out/thetavol_taskboard.html`.

## What the 2026-08-20 snapshot says

* **No double calendar qualifies.** Nine of ten names are in term-structure contango:
  you would buy the back leg richer than the front you sell. Only GLD has front IV
  above back IV (+0.43 vol points), and its forward factor is +0.036 against a +0.20
  entry rule. EWZ is at −9.40 vol points because the Brazilian general election sits
  inside the October expiry.
* **The smile is the live edge, not the level.** 25-delta risk reversal is −4.1 vol
  points on SPY and −5.2 on QQQ (rich put wing) but **+1.6 on GLD and +4.4 on SLV**
  (rich call wing) — precious-metals upside demand.
* **The income ceiling is 0.20% a month, not 2%.** Of 35 structures priced from live
  legs, 8 carry positive expectancy on the calm-regime measure and none across the
  full year.
* **The drawdown limit is not the binding constraint.** The optimised book uses $1,585
  of a $6,000 daily 99% VaR budget and saturates well below the cap. What limits
  income is the absence of edge.
* **It is the regime, not the idea.** Holding universe, correlations, forecasts and
  costs fixed and scaling only implied vol, the 2%-a-month target arrives at 1.60×
  today's level — SPY's 29-day ATM near 21% rather than 13.2%.

## Rules this code is written to obey

* Deltas come from the **implied forward** fitted per expiration, never from the
  spot print with a zero dividend yield.
* Term structure is interpolated in **total variance**, never linearly in vol.
* Risk-neutral EV is a tautology. Expectancy is measured against **real historical
  return distributions**, re-centred so `E[S_T] = F`, and reported both
  unconditionally and on a calm-regime subsample.
* Probabilities described as "share of real windows" are computed on the **raw**
  sample, not the re-centred one.
* **CVaR is reported alongside every score**, together with the number of
  *distinct* historical episodes the tail is drawn from.
* Execution cost is reported exactly: mid value less fill value.
* Ranking is by **dollar** expectancy, not EV/capital.
* Every price, IV and open-interest figure comes from an actual tool response and
  is labelled LIVE / LIVE-FROZEN / MODEL per figure.
* The scorecard surfaces honest FAILs rather than being retuned to pass.

## Not investment advice

This is analysis tooling. Every figure is an estimate produced from a model
calibrated to a single point in time.
